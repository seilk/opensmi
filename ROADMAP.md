# Roadmap

## Near-term
- Allocation UX polish (autocomplete, user picker, mouse interactions)
- Safer enforcement workflow (warn → grace period → kill)
- Audit log (append-only) + admin roles

## Mid-term
- Hard enforcement options (ACL / cgroups / scheduler integration)
- Pluggable collectors (Kubernetes, Slurm)
- Better state storage (SQLite with migrations)

## Long-term
- Multi-cluster support
- Web dashboard (optional)
